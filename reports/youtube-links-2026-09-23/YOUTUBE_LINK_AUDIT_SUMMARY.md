## 方法与边界

公开页面检查使用约每 1.2 秒一次的请求节奏，最多同时处理两条。异常链接和全部替代链接另用 yt-dlp 2026.08.19 的 simulate / skip-download 模式复查。没有登录、读取浏览器 cookies、绕过限制或下载音视频。

`playable` 表示检查时当前环境下 YouTube 返回可播放状态，不保证所有地区或未来时刻均可播放；本次没有逐首试听。yt-dlp 提示缺少受支持的 JavaScript runtime，但替代链接仍正常返回公开元数据和音频格式信息；未把该警告视为链接失效依据。

已写入旧日记的 Markdown 链接不会随内置曲库更新而自动改变。本次未修改插入、补填、清理逻辑。本报告记录审计时的结果；对应更新版本为 1.0.1，发布状态请查看 GitHub Releases。
